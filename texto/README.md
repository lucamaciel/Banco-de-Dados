# Texto extraído dos PDFs

Versões em texto puro dos PDFs, para facilitar a busca (Ctrl+F / grep) e a leitura.

- `slides/sldXX.txt`: slides do Prof. Wlad (`aulas/relational/slides`), e `SAM-spec.txt` com o projeto SAM completo.
- `camila/`: materiais de `material-camila/` (resumos, HOs, AS, provas, aulão, TP).

Atenção: AS01–AS04, P1 e P2 são PDFs escaneados (imagem), então os `.txt` deles saem praticamente vazios. Abra o PDF original em `material-camila/`.
A diagramação dos slides pode vir embaralhada. Na dúvida, confira no PDF.
