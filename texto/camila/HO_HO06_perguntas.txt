interpretar consultas em bancos de dados relacionais usando a linguagem de consulta
estruturada SQL (Structured Query Language).

Problema

relacional abaixo e especificar consultas em SQL para criar o esquema, as tabelas e restrições
(domínio, nulidade, unicidade, valor, valor padrão, chave e integridade referencial) do banco de
dados SAM.
