AS01

   Sistemas de banco de dados referem-se ao conjunto de dados
   relacionados e sua respectiva forma de acesso e organização.
   Formalmente, eles são compostos por uma coleção de dados organizados
   (banco de dados), uma estrutura lógica dos dados determinando a forma
   como podem ser armazenados, organizados e manipulados (modelo de
   dados), e um software que provê acesso ao banco de dados a usuários e
   aplicações (sistema gerenciador de banco de dados)
AS01
AS01

                          O modelo de dados é a forma como os dados
                          são organizados de forma conceitual. O
                          esquema é o projeto/estrutura física específica
                          de um banco de dados (tabelas, colunas,
                          linhas). Já o catálogo é o metadado que guarda
                          a descrição do próprio banco (dados sobre os
                          dados), gerenciado automaticamente pelo
                          SGBD.

      Gerenciamento de acesso concorrente

              A Arquitetura de Três Esquemas (interno, conceitual e externo)
              garante a Independência de Dados, que é a capacidade de alterar
              a estrutura em um nível do banco de dados sem precisar
              modificar o nível imediatamente superior. Isso facilita a
              manutenção e evolução do sistema, evitando que mudanças
              técnicas impactem as aplicações ou a visão dos usuários finais.
AS01
AS01

             SQL (Structured Query Language) é a linguagem padrão utilizada
             para interagir com Bancos de Dados Relacionais. Ela serve para
             criar, manipular, consultar e controlar a estrutura e os dados
             armazenados em um SGBD.

             Ela é composta de outras 4 linguagens:
                  VDL (definição da visão de usuário e esquema conceitual)
                  DDL (definição de dados do esquema conceitual)
                  SDL (definição de armazenamento do esquema interno)
                  DML (linguagem de manipulação de dados)
