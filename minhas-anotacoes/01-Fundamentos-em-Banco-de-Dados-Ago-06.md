# Aula 01 — Fundamentos em Banco de Dados

Módulo: MD01
Data: Ago-06

Resumo:

- O sistema de banco de dados (SBD) é composto por uma coleção de dados relacionados, uma estrutura lógica (modelo de dados) e um software que provê acesso aos dados.
- O banco de dados (BD) é a coleção de dados organizados que atende necessidades específicas dos usuários, presente em ambientes como reservas de hotel, bibliotecas, catálogos de filmes, supermercados e caixas bancários.
- Um SGBD (Sistema Gerenciador de Banco de Dados) permite definir, construir, manipular e compartilhar dados, oferecendo controle de redundância, abstração, autodescrição e suporte a múltiplas visões e transações multiusuário.
- O projeto de banco de dados passa por etapas: especificação do minimundo, análise de requisitos, projeto conceitual, projeto lógico e projeto físico.
- Atores envolvidos: DBA, projetista, analista, programador e usuário.

Conceitos-chave:

- Dados: símbolos, sinais e códigos que representam fatos ou ocorrências.
- Informação: dados organizados com significado e relevância para um contexto.
- Modelo de Dados: estrutura lógica que define como os dados são armazenados, organizados e manipulados.
- SGBD: software que gerencia BD, armazena metadados em catálogo e permite operações de inserção, remoção, modificação e recuperação.
- Minimundo: universo de discurso que o banco de dados pretende representar.
- Projeto de BD: sequência contínua de passos para refletir o estado do minimundo.
