# Materiais de Aula — Banco de Dados

Este diretório centraliza os materiais do professor para estudo.

Objetivo
- Organizar slides, textos e exemplos por tópico para facilitar revisões e tarefas.

Estrutura
- aulas/
  - nosql/      — Documentação e imagens sobre NoSQL
  - relational/ — Slides, especificações e exemplos relacionais

Plano de estudo sugerido (prioridade)
1. MD01 — Fundamentos: ler `aulas/relational/README.md` e os slides iniciais
2. MD02 — Projeto Conceitual: estudar SAM.tex e o SAM.pdf em `aulas/relational/specs/SAM`
3. MD03 — Projeto Lógico / SQL: revisar slides de SQL em `aulas/relational/slides`
4. MD04 — Projeto Físico / Indexação / Otimização: focar nas seções de armazenamento e índices
5. MD05 — NoSQL: ler `aulas/nosql/README.md` e os documentos por tipo (document, column, graph)

Como estudar com estes arquivos
- Use os PDFs para revisão rápida; abra os .tex/.md para detalhes e exemplos.
- Faça anotações locais (ex.: pasta `minhas-anotacoes/`) e resolva exercícios com um SGBD local (SQLite/Postgres).
- Priorize os slides e exercícios antes das leituras longas.

Sugestões de organização pessoal
- Criar `minhas-anotacoes/` para resumos por aula.
- Criar `exercicios/` para scripts SQL e dumps de teste.

Se quiser, crio automaticamente `minhas-anotacoes/` e `exercicios/` e adiciono um template de estudo.

---
Arquivos importantes:
- `aulas/relational/slides/` — slides das aulas
- `aulas/relational/specs/SAM/` — especificação e exemplos (útil para modelagem ER)
- `aulas/nosql/docs/` — textos explicativos sobre tipos NoSQL

Bom estudo! Se quiser, organizo sub-índices por módulo e crio templates de anotação/exercício.
